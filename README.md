# Cafezi

Cafezi is a proprietary static HTML, CSS, and JavaScript website template for cafes, coffee shops, coffeehouses, espresso bars, and specialty coffee brands.

## About

Cafezi is designed as a polished, lightweight web presence for menus, locations, brand storytelling, specialty drinks, roasted coffee, pastries, and customer calls to action. The repository remains public for project visibility while all source code and creative work remain proprietary.

## Project Scope

- Brand: Cafezi
- Repository: `eduardosrios/cafezi`
- Project type: static website template
- Stack: HTML, CSS, JavaScript
- Domain focus: coffee shops, cafes, coffee roasteries, specialty drinks, pastries, brunch, and neighborhood hospitality

## Status

Cafezi is in active development. Approved website files will be published after implementation, quality assurance, accessibility review, and release validation are complete.
