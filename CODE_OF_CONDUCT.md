# Code of Conduct

## Our Commitment

This project is maintained to support professional, respectful collaboration around the Cafezi website template.

Everyone who participates in issues, pull requests, discussions, or any related project space is expected to communicate clearly, respectfully, and constructively.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experience levels.
- Keep feedback focused on the work, not the person.
- Accept constructive criticism professionally.
- Prioritize the best outcome for the project and its users.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or conduct.
- Sexualized language or unwelcome attention.
- Public or private harassment.
- Publishing private information without explicit permission.
- Any behavior that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Project maintainers may remove comments, reject contributions, block users, or take other reasonable action when behavior violates this Code of Conduct.

Reports can be sent privately to the repository owner.
