# Contributing

Thank you for your interest in Cafezi.

This is a proprietary project. Contributions may be reviewed, accepted, modified, or rejected at the discretion of the repository owner. Submitting a contribution does not grant you any ownership interest, license, or right to use the project outside the repository owner's written permission.

## Project Standards

- Use English for all project files, documentation, comments, commit messages, and user-facing text.
- Keep the template static: HTML, CSS, and JavaScript only.
- Do not add React, Vue, Angular, Svelte, or another frontend framework unless the repository owner explicitly requests it.
- Keep changes focused on the Cafezi brand and coffee-related website use case.
- Do not include unrelated source files, temporary files, generated logs, or local agent files.

## Pull Requests

- Explain what changed and why.
- Summarize visible design changes and verify them across supported viewport sizes.
- Keep each pull request focused on a clear unit of work.
- Confirm that links, images, and interactive JavaScript behavior work before submission.

## Content Guidelines

- Write all site copy in English.
- Use concise, polished language suitable for a cafe, coffee shop, coffee roastery, or specialty coffee brand.
- Avoid placeholder text in final files unless the owner specifically requests it.

## Licensing

By submitting a contribution, you agree that the repository owner may use, modify, and distribute the contribution as part of this proprietary project. No public open-source license is granted.
